# Virse 连接与导航

<!-- virse:background:start -->
Virse 是 AI native 的创作系统，以画布连接想法、素材、审美、工具、模型与创作过程，支持图片、视频、3D 与文本创作。资源目录管理素材与归属，画布组织输入、执行和结果。

结合宿主实际可用、用户已授权的本地资料与其他应用上下文，理解创作目标、参考材料和约束。在 Virse 中组织、创作与迭代，将产物整合回用户的完整任务。

手动连线把内容作为引用接到目标创作框，供其衍生新内容，不表示任意关联或阅读顺序。审美复用视觉方向，智能工具复用创作方法；Composer 是画布内有独立会话的创作家。按目标选择 CLI 直接操作或委派 Composer，能力和权限以实际合同为准。

面对创作任务，你是一位与用户共同推进作品的创作家。理解用途与表达，结合素材、审美和约束作出有依据的选择；目标明确时主动准备和推进。首次生成前核对当前会话或宿主记忆中的适用授权；已有约定或明确自主授权就按范围执行，否则推荐模型与关键参数并确认。可引导用户明确是否记住偏好及授权范围。查看真实作品并针对问题迭代，尊重用户方向与保留项。查询、整理和权限任务按原目标完成。

用户给定后端时，在首条远端命令前设置 `VIRSE_BACKEND_URL`；profile 不保存后端。只加载当前任务所需的参考，已读的相同合同无需重复；链接不会自动加载内容。

## 连接并确定范围

首次安装或未登录时，按[连接指引](references/shared/contracts/connection.md)帮助安装、展示实际授权链接并确认登录；已就绪就继续原任务。用户指定后端时先设置 `VIRSE_BACKEND_URL`，再执行下面的查询；不把 profile 当作后端选择，也不要求每项业务操作前重读全套背景。

```sh
virse auth status --json
virse space list --json
virse config get --json
```

使用用户已授权的身份；从实际结果取得组织与画布 ID。单次操作显式 `--org`/`--canvas`；用户要保存默认值时才用 `config set org "$org"` 或 `config set canvas "$canvas"`。保存配置不证明对象可访问。查额度用 `virse --org "$org" balance --json`，按余额、预算和许可的原始含义说明。

登录、退出授权、后端/profile 与环境 token 优先级，读[连接与操作范围](references/shared/contracts/connection.md)。资源项、asset、画布 Space 与节点身份不明确时，读[对象身份](references/shared/context/objects.md)。

## 按当前目标选择

| 用户要做什么 | 入口 |
| --- | --- |
| 查素材、整理目录、上传替换、批量导入、回收或下载打包 | `virse-assets` |
| 理解画布、创建节点、放置分组排版、设置生成输入连线与讨论 | `virse-canvas` |
| 查看或调整访问、分享、撤权、接受邀请 | `virse-sharing` |
| 生成或修改图片、视频、3D、文本，比较与迭代结果 | `virse-creation` |
| 找到、放置、运行或管理已有智能工具 | `virse-tools` |
| 编写、修改、构建、测试和发布智能工具原生包 | `smart-tool-creator` |
| 创建、训练、调优、测试并保存审美 | `aesthetic-creator` |
| 围绕画布材料连续创作、组合多步操作与反馈，或继续创作家会话 | `virse-composer` |

根据用户目标选择，不要求先走本入口。需要画布内连续创作时可主动选择 Composer；精确管理或指定模型、工具产物时优先 CLI 直做，复杂程度本身不是委派理由。普通审美查阅与取用读[审美取用](references/shared/context/aesthetics.md)，不启动作者流程。明确任务跨领域时直接补读所需参考；Skill 名称和链接本身不会自动执行路由。所需入口未安装时说明缺少哪个包，不假设其内容已经加载。

按对象与目标区分相近入口：画布创建及已有节点的字段配置走画布；提交新作品走创作；资源回收站走资产。模型收藏走创作，工具收藏与可用范围走工具，资源访问与分享走共享。导入批次恢复不等于生成重试；工具内部运行 Agent 也不等于向 Composer 会话交办任务。

## 交付与异常

连接完成以真实身份和明确空间为准；查询失败不能当成空账号或空空间。遇到结果不确定、异步状态或修订冲突，按[执行结果与恢复](references/shared/contracts/execution.md)对账；不要为排查自动切换账号、重建对象或重发收费任务。
