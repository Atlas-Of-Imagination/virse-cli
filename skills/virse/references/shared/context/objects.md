# 空间、资源与画布身份

空间是个人或团队的资源与使用额度范围。选择 `--org` 或保存默认组织，只改变本次操作上下文，不迁移资源归属；团队角色也不能替代具体资源权限。

媒体素材是实际内容，画布元素是它在某张画布中的使用实例，另有名称、位置、连线和继续创作设置；空创作框尚未绑定生成结果。生成任务记录一次执行，节点当前内容、待生成配置与历史输入分别核对。素材放入画布保留来源资源，目录整理、画布排版和内容创作作用于不同对象。

| 对象 | 用在哪里 | 如何确认 |
| --- | --- | --- |
| organization ID | `--org`，资源目录与额度 | `space list`，保留个人/团队类型与本人角色 |
| resource/dentry ID | 目录项、文件夹、分享、回收站 | `resource get`；路径也可解析成该身份 |
| asset ID | 媒体内容及原件 | 从实际资源/节点结果取得，不把 resource ID 换名使用 |
| canvas Space ID | `--canvas`，画布结构与生成上下文 | 从资源实际关联或 `canvas list/get` 取得，不能把画布目录项 ID 直接代入 |
| element/group/edge ID | 画布内节点、组合与生成输入关系 | 画布结构查询；组合成员是内容节点，不是协作者 |
| task/run/turn ID | 生成、工具、训练或 Composer 的一次执行 | 对应提交回执与状态查询，分别保留 |
| tool/artifact/release/revision | 工具身份、不可变包、正式发布、草稿修订 | 对应工具接口；版本标签不能代替 artifact ID |

资源目录路径区分大小写，只接受 `/`、绝对资源路径、`@UUID` 或裸资源项 UUID；没有工作目录、`..` 或 shell 通配。画布在资源树中是文件项，不是可继续遍历的文件夹。同名解析有候选时先消歧；完成操作后保留实际 ID，不用显示名称充当身份。

读取目录或搜索结果有续页时，沿原范围和筛选继续；`tree` 达到深度或条数上限时不代表读完。`canvas contents` 是媒体等内容投影，返回空不证明没有文本或工具节点；完整盘点用节点列表并读完分页。画布用途可由标题、文本、组合、实际媒体及生成参考关系判断；未标注区域的意义只能作为推断。

手动输入连线把源内容作为目标创作的引用，指定文字要求、图片参考等用途；目标运行时读取兼容输入，连线本身不启动创作。一般关联、素材出处与阅读顺序用文字、分组和布局说明。Composer 到生成产物的来源连线由系统维护，与手动输入边分开理解，不据此推定 CLI 可编辑。文本可以是合法输入；连线已保存或事后补建，也不证明历史任务使用过该参考。

普通组合组织同一画布中的成员，成员仍保留自己的内容、参数与连线，不合成图片，也不形成资源目录或独立分享权限。审美组展开特定审美的参考图，搜索组组织查询与结果；按实际类型与操作合同处理，不直接套用普通组合规则。

审美复用视觉方向，智能工具封装输入要求、制作方法与输出约定，Composer 是平台内独立会话的创作家。资源整理不改变图内内容，画布布局不等于图内构图或 3D 姿态。
