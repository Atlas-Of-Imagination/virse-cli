# 参考与连续性

## 先说清素材的作用

一张图不天然等于首帧，一段视频不天然等于动作驱动。选择能表达本次角色的模型和输入模式，再绑定真实角色、数量与顺序。不要把“素材已上传”当成“模型已经知道该借用什么”。

| 参考作用 | 主要约束 | 模型仍需决定的内容 |
| --- | --- | --- |
| 首帧 | 起始构图、可见外观、姿态、光线与空间关系 | 后续运动、遮挡后的形态、未见角度 |
| 尾帧 | 结束状态与构图 | 到达终点的路径、速度、事件顺序 |
| 人物或产品形象 | 身份、轮廓、纹样和关键结构 | 新姿态、新视角、当前场景中的光影与接触 |
| 场景或风格 | 空间或视觉方向 | 新主体放置、动作和时序，不保证逐像素复制 |
| 动作或表演驱动 | 肢体、表情或运动节奏，取决于专用能力 | 与目标形象的适配，背景、镜头或音轨是否沿用 |
| 相机运动参考 | 观察路径与运动感，前提是模型明确支持 | 目标场景的几何关系与遮挡 |
| 音频参考 | 合同声明的节奏、语音、音色或音轨作用 | 不能自行推定会复制原音、生成对白或驱动口型 |
| 编辑源视频 | 原有时间变化与画面依据 | 编辑如何传播、哪些细节会被重新生成 |

## 首帧向前，尾帧向后，首尾补路径

只有首帧时，从图中实际姿态向前写。坐着的人先起身再行走；产品开始转动时，背景是否静止、转的是产品还是相机应清楚。要大幅转身或绕拍时，检查是否有足够的外观依据，单一正面图无法保证背面细节。

只有尾帧且模型明确支持该输入时，先从终点反推合理的起始状态与过渡。尾帧里纸船已展开为地图，可以写“折叠纸船的船沿逐渐向外摊平，折痕展开，最后平铺为尾帧中的地图”。这不意味着 Virse 的“首尾帧”入口支持只传尾帧；该产品任务要求首尾各一张，单尾帧要以当前 operation 的真实合同为准。

首尾都有时，图约束两端，文字负责中间为什么、怎样变化：

> 首帧中合拢的扇面从左向右逐根展开，扇骨围绕底部轴点转动；握柄保持在原位。扇面完全打开后短暂停住，抵达尾帧中的展开角度与构图。

先比较两图是否真能连接：主体数量、形状、姿态、相机位置、背景结构与光线。差异越大，模型越可能用变形、遮挡或切镜解决，不一定得到预期的连续运动。按目标选择修正端点、解释过渡、增加可用时长，或接受明确转场；不要一边要求无缝同镜，一边要求不可能的瞬时空间变化。

## 多参考分工

选择对目标确有帮助、彼此相容的素材。不同角度有助于补足身份与结构；重复但光照、服装或形体冲突的素材可能降低约束的清晰度。不要把最大参考数量当成默认应传数量。

提交前给每份素材确定作用，例如：

| 素材 | 取用 | 不应连带复制 |
| --- | --- | --- |
| 人物正面照与侧面照 | 同一人的脸型、发型、身材 | 两张照片各自的背景与拍照姿势 |
| 饮料瓶图片 | 瓶型、瓶盖、标签位置 | 产品摄影的底座和背景 |
| 桌边动作视频 | 手拿起瓶子、转动手腕的动作节奏 | 视频中演员的身份、衣服和场景 |

正文可写“使用人物参考中的形象、产品参考中的瓶子；借用动作视频中拿起瓶子的节奏”。实际引用标记、角色字段及引用顺序必须替换成当前模型能识别的形式；不发明通用的 `@人物` 绑定语法。若模型只把视频当整体内容参考，不能承诺实现专用动作迁移。

## 连续性按重要项检查

- **身份与物体**：脸、发型、服装、产品比例、部件数量和标签；在转身、遮挡、手持接触处重点看。
- **空间**：人物左右关系、出入口、家具与物体位置、视线方向；相机运动不应随意改变物体之间的关系。
- **动作状态**：接触点、受力方向、持物手、动作进度；下一阶段应从上一阶段的真实状态继续。
- **光线与材质**：光源方向、明暗过渡、反射和阴影是否随运动合理变化；“保持”不等于冻结高光。
- **声音**：同一说话人的音色、环境底噪、音乐与事件声的衔接；图像参考无法独自保证这些连续性。

先选最影响用途的保留项写进 prompt，再以结果验证。要求换场景时，照明和透视需要重新适配；要求保持身份时，不等于所有像素与原图不变。连续性对功能、身份或品牌至关重要而模型反复失守时，应换约束方式或制作路径。
