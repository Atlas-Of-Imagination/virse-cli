# 查看与迭代

## 先看实际发生了什么

取得有权查看的真实视频，结合本次目标播放检查。正常速度能判断节奏与整体观感；局部重放或慢看能定位动作、接触和遮挡问题；抽帧可辅助检查身份与构图；听音才能判断对白、音色、音乐和同步。

任务成功只代表处理状态。只看封面不能判断运动，只看若干帧不能认定整片无闪烁，只看静音视频不能认定声音正确。宿主不支持完整播放或声音时，明确已检查的范围和未验证项，不以猜测完成验收。

按用途选择检查重点，不强制每条片子都做相同的电影评价：

- 产品演示：结构、功能顺序、持握和接触、标签与关键细节是否可靠。
- 人物表演：身份、动作与反应、视线、肢体、说话人和口型是否一致。
- 抽象或图形动画：变形逻辑、节奏、边缘、停留和循环接点是否成立。
- 场景与空间：主体关系、相机轨迹、遮挡后内容、光线和空间是否连续。
- 编辑与续写：要求改的是否改到、保留项是否失守、接缝与音轨是否可用。

## 先定位原因，再改输入

| 真实结果中的问题 | 先检查什么 | 有依据的下一步 |
| --- | --- | --- |
| 画面漂亮但没有做核心动作 | 动作是否有明确主语、是否被次要要求挤掉、时长是否足够 | 突出核心变化，减少竞争事件或调整时长 |
| 图生明显偏离原图 | 图是否真正绑定首帧，文字是否重建了场景，原图本身是否有缺陷 | 修正角色或冲突描述，必要时先换干净首帧 |
| 首尾都像，中间乱变形或切镜 | 两端差异、结构可达性、过渡路径与可用时长 | 修正端点或补路径；无法连续时选择明确转场 |
| 相机和主体一起莫名旋转 | 谁在动、旋转轴和背景关系是否明确 | 分开主体与相机描述，保留必要的运动层 |
| 主体该静止却一直移动 | 首帧是否有扬尘、动态模糊或动作中的姿态 | 按[首帧运动线索](motion-and-camera.md)判断是否先修输入 |
| 手或物体穿透、接触突然消失 | 初始姿态、目标动作、遮挡、接触点与动作密度 | 修正输入姿态或缩小动作，补清接触及反应 |
| 人物、产品或背景漂移 | 参考角色、跨视角依据、遮挡后重现、长时间变化 | 补合适参考，减少无依据的视角变化，选择更适配路径 |
| 节奏赶、停顿长或事件丢失 | 时长、动作数量、对白长度和阶段分配 | 调整事件量与停留，必要时使用可行的分段制作 |
| 编辑顺带改了不该改的部分 | 指令是否变成整片重写，保留项是否可兼容，模型是否支持该编辑 | 缩小改动、补关键保留项，换更合适的编辑能力 |
| 续写接缝跳动或像重新开场 | 源片真实末状态、是否原生续写、返回范围与拼接方式 | 从末状态重写，修接点或明确采用新段转场 |
| 缺音、音色变了、台词或口型不对 | 输出是否有音轨，模型是否支持目标能力，参考究竟起什么作用 | 修正配置或改用适合的音频路径；未支持时分开制作 |

## 让每次改动能被判断

保留可比较的基准结果、参考、prompt 和关键参数，指出问题发生在哪段、哪个对象以及期待差异。优先改变最可能的原因，避免同时换主体、风格、镜头、时长和模型后无法判断改善来自哪里；若已确认路径选错，可以直接换路径。

例如：“瓶子转到侧面时标签漂到瓶后；本次保留首帧、机位和时长，先把动作改为小角度转动并补充标签位置约束。”新结果要回看相同位置，同时检查是否损伤了已经正确的部分。

若改 prompt 仍反复出现同类结构、身份、精确时序或声音问题，重新判断参考质量、模式和模型能力，必要时选择实际可用的制作方式。不要把随机重抽当作已查明原因，也不无限增加强调词或盲目生成。继续执行遵守用户当前模型、费用与自主迭代范围；超出范围先说明具体取舍。

用户只要诊断时，给出已观察到的问题、仍不确定的原因和最小改进方向。用户要生成成品时，交付实际可用结果；未检查整片、未听音或未拼接的部分不能写成已完成。
