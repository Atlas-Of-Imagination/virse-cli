# 参数

## 先选任务，再查可用控制

只解释参数概念或给未绑定模型的方案时，直接说明取舍，无需登录或远端查询。需要核实特定模型的可用取值、组合限制或实际提交时，再读取当前模型目录。

`generation_capabilities.parameters` 是模型级定义；`audio_modes[任务].params` 是该任务允许的参数白名单，`param_overrides` 按任务覆盖默认值、范围、数量或必填。生效定义 = 模型级定义与该任务覆盖的浅合并；不在白名单里的参数服务端会丢弃。源码或厂商文档里有某参数，不证明当前后端或账号已开放。

快捷入口没有 `--mode` 或 `--voice` 这类专用 flag；任务模式与参数都写进 `--parameters` 或 `--parameters-file` 的 JSON 对象，`audio_mode` 必填。生成次数用 `--count`。

## 参数类型与提交形状

| 类型 | 提交形状 | 说明 |
| --- | --- | --- |
| `enum` | 选项之一 | 如分轨档位、对白处理方式 |
| `boolean` | `true` / `false` | 如循环、降噪 |
| `integer` / `decimal` | 数值；声明 `allow_auto` 时可取 `"auto"` | 时长、语速、稳定性等；`unit` 说明秒、倍数或百分比 |
| `multiline` | 字符串 | 歌词、发音词典；`line_format` 为 `key_value` 时每行一条 `词=读音` |
| `voice` | 音色 id 数组，长度等于 `count` | 见[音色](voices.md) |
| `time_range` | `{"start": 秒, "end": 秒}` | 区间重做等；`bound_input` 指向时长来源的槽位 |
| `segments` | `[{"start": 秒, "end": 秒, "prompt": "..."}]` | 分段描述；首段与衔接规则看 `contiguous_from_zero` |

`required` 的参数缺失会被拒绝；`group` 为 `advanced` 的参数通常可以保留默认值。

## 让参数服务于创作判断

| 控制 | 什么时候有用 | 与输入和效果的耦合 |
| --- | --- | --- |
| 时长 | 适配投放位置、画面长度或循环需求 | 范围随任务与素材变化；更长不等于内容更丰富，音乐可能重复或结构松散 |
| `audio_count`（快捷命令 `--count`） | 需要多份候选比较 | 请求顶层字段，不放在 parameters 里；输出数随之成倍增加，费用同样；模型可能另有更小的上限 |
| 语速、音高、情绪 | 台词表达需要更明确的方向 | 极端取值容易失真；情绪参数与台词内容冲突时听感别扭 |
| 稳定性、相似度、描述跟随强度 | 平衡一致与变化 | 不同模型含义不同，不能默认数值越高越好 |
| 区间 `time_range` | 只重做一段 | `0 ≤ start < end ≤` 素材时长，长度在 `min_length`–`max_length` 内；声明 `length_param` 时区间长度须等于该参数 |
| 前后延长 | 续写在开头或结尾补多长 | 延长越长，越可能偏离原曲风格 |
| 歌词 | 自定义歌词或改编 | 长度受 `min_length`、`max_length` 限制；必填与否随任务变化 |
| 分轨档位、对白处理 | 决定输出轨道 | 会改变轨数与输出数，见[多轨与转写](tracks-and-transcripts.md) |
| 循环 | 背景音或音效需要无缝循环 | 生效与否以模型实际结果为准，交付前听接缝 |

画布节点的显示尺寸与音频时长、采样率无关；prompt 里写“30 秒”也不等于时长参数已设置。

## 处理组合约束

先核对决定任务的输入，再核对交付参数。常见冲突包括：任务不在所选模型的 `audio_modes` 里、必需输入缺失、素材时长越界、互斥的槽位同时有输入、音色数量与 `count` 不符、区间超出素材时长。

参数报错时先修输入与目录合同；效果差时先判断任务模式、素材与描述是否合理。不要为提升音质自行更换用户指定的音色、任务或模型。

首次生成前按 `virse-creation` 核对已有模型与参数约定或明确自主授权。偏好、历史配置或一次确认不自动扩大授权范围；需要改变关键选择且不在已有范围内时，说明推荐及理由并确认。
