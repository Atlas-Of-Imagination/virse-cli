# 查看与迭代

## 先听实际发生了什么

取得有权查看的真实音频，结合本次目标完整播放。正常速度判断节奏与整体听感；重听局部定位读错、断音、杂音和接缝；对照源音频判断保留项是否守住。波形、时长与文件大小只能说明有内容，不能代替听音。

任务成功只代表处理状态。宿主不支持播放或音频理解时，明确已检查的范围和未验证项，不以猜测完成验收。

按用途选择检查重点：

- 配音与旁白：台词是否完整、读音是否正确、停顿与语速是否合适、音色是否符合角色。
- 双人对白：说话人是否对应、两个声音是否可区分、轮次是否连贯。
- 换声：内容与节奏是否保留、新音色是否稳定、有无机械感或残留原声。
- 音乐：风格与配器、速度感、结构起落、人声与歌词是否清楚、结尾是否完整。
- 音效与拟音：声源是否对、动作与声音是否对齐、空间与距离感、是否盖过对白。
- 区间重做与续写：接缝处有无跳变，速度、调性与音色是否连续，改动是否只落在目标段。
- 分轨与分离：每轨是否只含目标声音、残留程度、叠加后是否接近原曲。
- 转写：文本与原音频是否一致，见[多轨与转写](tracks-and-transcripts.md)。

## 先定位原因，再改输入

| 真实结果中的问题 | 先检查什么 | 有依据的下一步 |
| --- | --- | --- |
| 把说明文字也念出来了 | prompt 是否混入了表达说明 | 说明改用参数或模型支持的标签，台词只留要念的字 |
| 读错数字、专名或多音字 | 写法是否有歧义，模型是否有发音词典参数 | 改写成明确读法或填写发音词典 |
| 语速赶、吞字或截断 | 台词长度、标点、时长与字数上限 | 拆短句、加停顿，必要时分段生成 |
| 对白说话人对调或混在一起 | `Speaker` 标签与音色数组顺序 | 修正标签或调换音色顺序，选更易区分的音色 |
| 音色不像预期 | 音色 id 是否属于该模型，参考录音是否干净 | 试听候选音色，换更干净的参考 |
| 换声后有噪音或原声残留 | 源录音质量、是否开启降噪 | 先处理源音频或开启已声明的降噪 |
| 音乐风格偏、结构散 | 描述是否过多堆叠、时长是否合理 | 收紧风格与配器，写清段落起落 |
| 自定义歌词唱错或漏唱 | 歌词是否放在歌词参数、长度与分段 | 修正歌词位置与分段，缩短过长的段落 |
| 音效声源不对或空间感错 | 描述是否写清声源、材质、距离 | 补充具体动作与空间，删去抽象形容 |
| 拟音与画面不同步 | 源视频动作是否清晰、模型是否支持对齐 | 换更合适的任务或模型；精确卡点交后期 |
| 区间重做或续写接缝明显 | 区间边界、前后上下文、延长长度 | 调整区间到更自然的接点，缩短延长 |
| 分轨残留严重 | 源音频混音密度、所选档位 | 换档位或模型，告知残留程度 |

## 让每次改动能被判断

保留可比较的基准结果、台词或描述、音色和关键参数，指出问题发生在哪一段、哪条轨道以及期待差异。优先改变最可能的原因，避免同时换台词、音色、任务和模型后无法判断改善来自哪里；若已确认任务模式选错，可以直接换任务。

例如：“第二句把‘行’读成了 háng；本次保留音色和语速，只把句子改写为‘可以，没问题’。”新结果要回听相同位置，同时检查是否损伤了已经正确的部分。

若反复出现同类读音、音色或结构问题，重新判断素材、任务模式和模型能力，必要时选择实际可用的制作方式。不要把随机重抽当作已查明原因，也不盲目增加生成次数。继续执行遵守用户当前模型、费用与自主迭代范围；超出范围先说明具体取舍。

用户只要诊断时，给出已听到的问题、仍不确定的原因和最小改进方向。用户要成品时，交付实际可用结果；未听完整段、未核对每轨或未对照转写的部分不能写成已完成。
