# 灵感探索

## 理解线索与对齐方向

结合用户描述、参考图、画布、常用网站、创作者或收藏链接，理解用户要发展概念、内容或故事，聚焦视觉方向，提炼创作元素，还是收集参考；目标可以结合。信息足够就推进，只补问影响选择的缺口。

开场确认是否有指定画布，已给出则沿用，没有则新建。使用已有画布时，查看相关区域、文字与真实媒体，区分必须保留的内容和仅供启发的材料。

搜索前简短对齐对象、感觉与用途：“杯子的广告”偏向对象与表现案例，“清凉”可以跨光线、材质、动作和场景寻找，两者也可组合。用户只说“开启灵感探索模式”时，再问探索主题与画布，也可邀请其提供参考和常用来源。

## 查找与筛选

用宿主可用的搜索、浏览和看图工具研究外部作品，通过 Virse CLI 读取与落地画布。结合用户常用来源，按当前问题选择网站，结果不足再扩展；也可推荐适合本次方向的网站。

以下仅是参考起点，不逐站遍历；主动发现优质独立网站、工作室与创作者，沿作品署名、项目说明和相关作品继续探索。X 等社交平台也可发现线索，追到原作者和项目后判断。

| 想找什么 | 可参考的来源 |
| --- | --- |
| 品牌、平面与完整项目 | [Behance](https://www.behance.net/)、[站酷](https://www.zcool.com.cn/) |
| 广告概念、产品表达与包装 | [Ads of the World](https://www.adsoftheworld.com/)、[Packaging of the World](https://packagingoftheworld.com/) |
| 跨媒介创意、插画、艺术与材料感觉 | [It’s Nice That](https://www.itsnicethat.com/)、[Colossal](https://www.thisiscolossal.com/) |
| 视觉联想、长尾线索与主题收藏 | [Are.na](https://www.are.na/)、[Pinterest](https://www.pinterest.com/ideas/)；继续追到原作者与项目 |
| 电影构图、光色与动态叙事 | [FilmGrab](https://film-grab.com/)、[Directors’ Library](https://directorslibrary.com/) |
| 真实生活、摄影叙事与历史艺术 | [Magnum Photos](https://www.magnumphotos.com/)、[The Met Collection](https://www.metmuseum.org/art/collection) |
| 角色、场景、道具与概念设定 | [ArtStation](https://www.artstation.com/) |
| 独立团队与创作者的原始作品 | 如 [Pentagram](https://www.pentagram.com/work)、[Studio Dumbar](https://studiodumbar.com/work)、[Christoph Niemann](https://www.christophniemann.com/overview/works/) |

实际打开作品和图片，检查任务关联、可借鉴的表达、清晰度、压缩、遮挡与细节，不凭站点名气或缩略图选入。质量服务于用途，粗粝的表达也可能适合任务；不固定风格、媒介、图片或方向数量。

遇到登录限制且影响继续时，说明网站和原因，引导用户在浏览器登录后继续。访问、订阅与下载条件以当前页面为准；区分缩略图、展示图和实际取得的文件。无法取得时说明缺口，换来源或请用户提供，不把仅有链接说成已放入图片。

方向有实质分歧时，展示实际看过的代表图与借鉴点，请用户选择、舍弃或组合，再调整搜索。目标明确或已授权自主筛选时直接推进。

## 整理到画布并交付

将精选图片通过 CLI 上传并放置到目标画布，配上适用的概念、故事或创作元素、简短解释及作者和原始项目链接。保留图片与出处的对应关系，区分观察、创意推断与已确认方向。用分组、文字和布局组织内容，手动连线只用于真实的创作输入。

创建、读取和排版按需补读 `virse-canvas` 的对应参考，上传补读 `virse-assets`。用户要试做作品时再进入生成，沿用已有的模型、参数确认与授权规则。

交付前核对真实画布、节点、素材、出处与布局；有前端查看条件时检查图片显示、文字可读性和遮挡，否则说明可见效果未验证。返回经核实的画布链接，简述方向与待选事项。写入受阻时明确画布交付未完成，并保留已整理材料。
