# 画布整理

## 先看内容，再商定整理方式

沿用用户指定的画布与区域；目标不明时先定位。按[理解与取材](read-select.md)浏览整体结构，再按需查看真实素材，理解文字、节点、已有分组与创作引用关系。简短说明实际有哪些内容、已有组织方式，以及哪些用途只是推断，不能仅凭名称归类。

结合用户用途和真实内容，提出具体整理建议：哪些实际建组、哪些仅做空间分区，组名与成员、组内与组间如何排列，以及零散内容如何收纳。疑似重复、过时或用途不明的内容先提出保留、收纳或移除建议，由用户决定。

用户确认整理方式后再写入；已有确认的范围、规则和保留项沿用，不重复询问。用户调整方案时保留其修改，不把“帮我整理”直接当成任意重组或清理的授权。

## 按内容选用整理参考

| 参考方式 | 适合的情况 |
| --- | --- |
| 按主题或项目分区 | 同一画布混有不同项目、对象或创意方向 |
| 按创作阶段组织 | 需要看清参考、尝试、候选与定稿 |
| 按方案并排对照 | 需要比较多个方向或同类变体 |
| 按创意单元组织 | 同一想法的参考、说明、尝试与结果适合就近查看 |

这些方法可组合，也可采用用户自己的约定，不套固定模板。适合一起移动或管理的内容可以实际建组；仅需就近阅读的内容也可保持独立，只调整空间位置。保留已有分组中仍适用的组织方式。

横排便于比较，纵排适合顺序阅读，网格适合浏览平行候选；按内容决定顺序、对齐、间距与留白。显示尺寸服务于比较或重点表达，保留素材比例与文字可读性，需要时建议简短标题或说明。涉及新增文字、改名或移除时，把这些纳入待确认方案。

## 执行与核对

在确认范围内调整分组、命名和布局，保留作品内容、创作配置、引用关系及用户指定的保留项。一般说明和阅读顺序用文字、分组与位置表达；手动连线只用于真实的创作输入。

准备分组、改名或调整成员时，补读[编辑对象与关系](edit-graph.md)；移动排版时，补读[放置、排版与复制](layout-copy.md)。只读当前动作需要的说明，已读且仍适用的内容沿用。

核对实际保存的节点、组名、成员、布局与引用关系，确认处理范围符合约定。有前端查看条件时检查真实显示、文字可读性与遮挡；否则说明可见效果未验证。返回实际画布链接，简述整理结果与仍待用户决定的事项。
