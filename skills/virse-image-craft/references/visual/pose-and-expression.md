# 姿态与表情

人物、动物或拟人角色动作僵硬、互动不明或情绪错位时，先看动作主线和受力，再看手指、衣纹等细节。姿态传达的是正在做什么以及身体怎样参与；站姿稳定不等于必须对称，动势强也不等于四肢伸展。

## 让动作有原因

| 目标与作用 | 选择和表达 | 取舍、问题诊断 |
| --- | --- | --- |
| 稳定站立或坐下 | 写支撑点、身体朝向，如“重心落在左腿，右脚轻点地面，骨盆略向左移” | 静态平衡看重心与支撑关系；奔跑、跳跃不能按静止站立判定 |
| 表现运动 | 抓身体整体方向、伸展与收缩，如“身体前倾追赶，后腿离地，手臂与步伐交错” | 先让剪影能读出动作，过多小动作可能破坏主线 |
| 抓握、倚靠、搬动 | 指明接触对象、位置和受力，如“双手托住箱底，箱重使肩膀稍下沉” | 查穿透、悬空、手指方向与物体重量是否相容 |
| 表现情绪 | 结合眼神、眉眼、嘴部与身体，如“压住笑意，嘴角微扬，眼睛看向画面外的朋友，肩膀放松” | 情绪词可定方向，细节用于校准；不要求每种情绪都对应固定表情模板 |
| 多人互动 | 定谁看谁、谁遮谁、谁的手接触哪里 | 身份混淆、手臂归属错误时补清关系或姿态参考，不靠增加人数细节 |

先确认视角能否读出目标动作。双手在身后无法展示手中物品；极端俯拍可能削弱腿部伸展。复杂动作可用姿态参考约束相对位置，但原图身份和服装是否沿用要另说。

角色画可放大弧线、形变、表情幅度；写实肖像更在意局部变化和一致性；木偶、机械角色应按其关节和材质能否运动判断。不是所有作品都需要人体解剖细节，几何分析也不必进入提示词。

检查时区分动作不清、受力不对、局部连接错与神态不符。动作正确只一只手异常，评估局部修复；人物整体重心与姿势错误，补整体姿态比只修手更有效。表情在近看成立但用途是小头像，应简化背景或调整取景，而非无限夸大五官。

方法参考：[Proko 动势与动作关系](https://www.proko.com/course-lesson/how-to-draw-gesture)。
