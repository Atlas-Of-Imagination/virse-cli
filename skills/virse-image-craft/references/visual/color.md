# 色彩关系

配色不统一、重点不突出或颜色“脏”时，先看相对关系，再改颜色名称。颜色感受受相邻颜色、明度、面积和环境光影响；同一个红色放在不同背景上会有不同的显眼程度。不能只靠堆十六进制色值保证生成图中的精确颜色。

| 想达到的目标 | 可选择的关系与表达 | 取舍、诊断 |
| --- | --- | --- |
| 主体更醒目 | 改主体与周围的明度、饱和度、冷暖或面积关系，如“背景整体偏低饱和，红伞是局部较鲜明的色块” | 不必一律提高主体饱和度；如果背景更亮、更锐，仍会抢视线 |
| 统一一组颜色 | 选主色关系与允许变化，如“各场景保留偏暖纸色和深蓝线条，点缀色随章节变化” | 统一不是全图染成一个色；不同对象仍需可辨 |
| 表现温度或情绪 | 结合用途选冷暖、明暗与纯度；可描述“温暖室内光与窗外冷蓝暮色形成对照” | 冷色不必悲伤，暖色不必快乐；避免把情绪套进固定色板 |
| 保持品牌或产品颜色 | 用批准参考与明确颜色要求约束，检查目标区域在环境光下的表现 | 源图、色彩管理、输出与显示都会影响精确颜色；关键色可用后期校色核对 |
| 多彩而不乱 | 分配各色的角色、面积和强弱，如“大面积亮黄色，少量紫色结构线，多彩人物服装保持中等饱和” | 多色可以成立；若每块都同样鲜艳、同样大，先建立主次 |

黑白或灰阶检查能帮助看明暗区分：两个颜色色相不同但明度接近，缩小后可能粘在一起。它是诊断工具，不要求所有作品先做灰阶；依赖色相区分的作品也不因此被判错。

例：儿童拼贴可保留高饱和色，但让背景大色块和角色轮廓有清楚差异；水墨可用很少的朱红建立焦点；写实人物需让环境色影响皮肤而不失识别特征；霓虹画面可以多色，但脸部必要结构应按用途可读。

“脏”可能来自饱和度同时偏低、明暗缺层级、互补色混杂、局部色温不合或压缩污染，不能统一归因于颜色太多。“太艳”先找过强的区域，局部收敛比全图降饱和更可能保住意图。用户明确追求强烈冲突时，保留冲突，修可读性即可。
