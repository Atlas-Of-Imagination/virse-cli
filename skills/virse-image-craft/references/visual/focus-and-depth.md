# 焦点与空间

需要引导视线、展示产品细节、交代环境或修正“像平面贴上去”时，分别判断注意焦点、光学焦点和空间层次。第一眼看哪里不只由清晰度决定；对比、亮度、颜色、位置、表情和文字都可能更强。

| 选择 | 作用与可用表达 | 取舍、诊断 |
| --- | --- | --- |
| 清晰范围 | 浅景深强调某一距离，较大景深帮助同时读取多个距离的信息；写“眼睛与手中戒指清晰，远处街景柔化”比只写“f/1.4”更贴近目标 | 同时清楚的对象须有合理距离关系；不能让重要标签因惯用浅景深而模糊 |
| 前、中、后层 | 遮挡、相对尺度、透视与细节差异让空间成立，如“前景树叶略遮边，中景角色完整，远山细节较少” | 层次不是必须加三层道具；平面图标、纹样可不追求纵深 |
| 边缘和细节分配 | 焦点附近可更明确，次要区域可更简化；适用于绘画、版画、拼贴等 | 不是全部背景都必须模糊；统一锐化会抹掉有意的边缘层次 |
| 空气与距离 | 在适合的环境里用远处较低对比、偏环境色或雾化表达距离 | 清透天气、图形风格不必强加空气透视，过多雾会损失信息 |

摄影语言可作为画面描述，不能视为生成器在真实模拟相机。光圈、焦距、拍摄距离都会影响实际摄影的空间与景深，单个数值不保证结果；不能由成图断言精确镜头型号或曝光设置。

例：美食细节图可让前方食物清晰、背景餐厅柔化；建筑介绍需要空间关系与关键构件可读，适合更广的清晰范围；绘本可通过重叠与色块区分远近，无需镜头虚化；技术剖面图应保护标注和对应结构，不因“氛围感”降低可读性。

焦点不突出先查是否有更亮、更饱和或更密集的次要区域；整体扁平先查遮挡、尺度和明暗关系；只某个部位意外模糊，则检查焦点选择和清晰范围。别把主体比例、材质纹理或低分辨率问题都当作景深问题。选择一个与用途相关的改变，再看真实结果。
