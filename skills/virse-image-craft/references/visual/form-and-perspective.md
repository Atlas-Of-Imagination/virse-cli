# 形体与透视

主体“像但不对”、产品结构变形、部件接不上时，先判断目标要求怎样的形准。写实商品图重视真实比例与结构；卡通可以夸张头身，抽象画可以扭曲空间，但识别特征和内部逻辑仍应服务表达。不要把有意的风格化全部修成写实。

## 从外形到连接找问题

| 看什么、理解什么 | 怎样按目标表达 | 取舍与诊断 |
| --- | --- | --- |
| 外轮廓：整体辨认和大比例 | “瓶肩平缓过渡到窄瓶颈，瓶身保持直立，不收腰” | 先修大形；纹理再精细也掩盖不了轮廓错误 |
| 关键部件：决定这是什么、能否使用 | “杯柄与杯身上下两处连接，杯口完整可见” | 优先查缺失、重复、位置错，不惯性描述所有细节 |
| 体块：朝向和体积如何成立 | 将复杂主体暂看作有朝向的简单体积，判断前面、侧面、顶部是否一致 | 几何用于分析；除非需要积木、低多边形等效果，不把“球体圆柱方块”强塞 prompt |
| 连接与遮挡：部件属于谁、怎样衔接 | “前臂从袖口伸出，手握住伞柄，伞柄经过手掌而非穿透手背” | 遮挡可隐藏连接，不能把不可见部位断言为错误 |
| 透视：同一空间中的尺度与朝向 | “略俯视的三分之四视角，能看到桌面，四脚落在同一地面上” | 改视角会改变可见面与遮挡，不能又要求全图形状完全不变 |

需要准确比例时，用整体宽高、关键点间距、倾角、负形空间互相比对。参考是短宽产品而结果是细长产品，应指出瓶身宽高关系，不用“更准确”代替。不要依据单图中被遮挡或透视缩短的长度，直接推断真实尺寸；存在设计图或多视图时才有更可靠依据。

透视错误常见于同一平面的边线方向互不相容、圆口椭圆角度与物体轴向不符、远处物体反而无依据变大。平行边随深度汇聚适用于相应透视；等距图、正投影、儿童画或刻意多视点作品不按同一规则判错。选择的是空间表达方式，而非统一套用消失点。

例：商品图要求“保留参考中壶嘴长度、把手连接位置和壶盖轮廓，仅换表面颜色”；角色插画可要求“保留大头小身体的夸张，修正右臂与肩的连接”；扁平图标则先保证关键轮廓在小尺寸可辨，未必需要明暗塑体。

若结构长期失败，考虑更清晰的角度、结构参考、局部重绘或分层合成。不能仅添加“完美解剖”“精确透视”期待解决复杂关系，也不能从成图假称已恢复真实 3D 结构。
