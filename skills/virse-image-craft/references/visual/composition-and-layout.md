# 构图与排版

图片没有传达重点、放进使用位置不好裁，或图文互相挤压时，先看画面组织。构图决定观看顺序和元素关系，不等于固定使用三分法、居中或留白。热闹、压迫、平衡、疏离都可以成立，按用户要的感受选。

## 先分清画幅与主体比例

画幅是图像边界的宽高比；主体占比是主体在画面里有多大；主体自身比例是它内部的长宽与部件关系。三者分别处理。把方图改成横图，模型可能把主体也拉长；“主体更大”应表达取景更近、占画面更大，避免误改身体或产品形状。

| 目标 | 可用选择与表达 | 取舍、诊断 |
| --- | --- | --- |
| 看到环境关系 | 主体较小、保留周边线索，如“人物在巨大车站中显得很小，上部展示拱顶” | 重要表情可能不可读，不能同时要求极细脸部特写 |
| 看清主体或细节 | 近景、特写或较高占比，明确保留完整的哪些部位 | 主体被切可能是取景与“完整展示”冲突，先改边界关系 |
| 留出后加内容的位置 | 明确哪侧、多少相对空间、背景复杂度，如“右侧保留约三分之一平整墙面供排字” | 留白不必是白色；若图内已有完整文字，不重复留一块无用途空区 |
| 强调关系或方向 | 用视线、动作、形状、明暗引导；说明谁先被看到、谁在前后 | 斜线能带来动势，也可能破坏稳定感；按目标决定 |

先看缩略图中的大形和明暗块，再看细节。主体、背景、道具都同样鲜明时，只强化主体未必有效；也可降低某处对比、改变遮挡或位置。主体旁细线恰好接到头顶、轮廓贴边、重要部件互相遮住，常会造成误读；通过分离轮廓或改变接触关系修正，不必整体重画。

## 图内文字与信息

海报、封面、卡片、图解需要设计阅读顺序。先选第一信息，再用字号、字重、对比、位置或面积建立层级；不要求每张图都“大标题、小副标题”。相关内容靠近组成一组，组间留出更清楚的距离，共用对齐基准。装饰性错位和密集排版可以保留，但仍应让目标读者找到必要信息。

例：“复古演出海报，乐队名最大；演出时间与场地左对齐为一组，售票信息与该组拉开距离；插画的强对比区域避开小字。”比“排版专业”更容易检查。对儿童绘本，文字区要与主要动作错开；对信息密集的技术图解，分组、编号与对应关系优先于装饰。

读不清先分辨字形错误、字号过小、背景对比不足、间距拥挤还是阅读顺序错；分别选择改字、重排、简化背景或使用排版工具。仅增大清晰度不一定解决层级问题。实际生成逐字核对文案，精确文字与可编辑图形不能由位图外观代替。
