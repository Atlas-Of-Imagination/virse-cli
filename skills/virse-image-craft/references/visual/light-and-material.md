# 光线与材质

画面缺体积、主体融不进环境，或金属像塑料时，分开判断明暗组织、光源关系和表面响应。材质不是只靠名称与纹理；同一种材料在不同照明下可完全不同。插画可以压缩或重组光影，仍须符合选定的表达。

| 要解决的事 | 理解作用并选择表达 | 取舍、诊断 |
| --- | --- | --- |
| 明暗层级 | 大明暗块帮助辨认形体与焦点；可写“脸部保持可辨，外套融入较暗背景” | 全图同亮可能缺层次，但低对比并非错误；看是否符合柔和或平面化目标 |
| 光向 | 光源位置决定受光面、投影与高光关系；如“左上窗光，鼻影落向右下” | 多光源需说明作用；合成时影子与场景光源不符会暴露拼贴 |
| 光的软硬 | 相对较大的光源通常带来更软的阴影边缘；如“大窗漫射光”或“小型硬光投出清楚的影子” | 软光不等于没有阴影，硬光也能用于温暖、日常或幽默画面 |
| 反射与粗糙度 | 光滑表面反射较清楚，粗糙表面反射更分散；如“拉丝金属表面保留沿纹理方向拉长的高光” | “金属”不等于银色，镜面物体也不是纯白高光；要看环境反射 |
| 透明、透光与厚度 | 玻璃需看透射、反射、折射和边缘厚度；薄叶、蜡等可在逆光下透出柔光 | 透明物并非完全不可见；泛白可能是反光或雾面，先定位原因 |
| 接触与落地 | 接触阴影、遮挡和反射使对象与环境相连 | 影子不能代替真实接触；追求悬浮效果时不擅自补地面支撑 |

选择光线先看需要展示什么。看清包装文字可能需要控制镜面反光；展示玻璃厚度可借边缘反光和有区别的背景；表现粗陶可用能显现起伏的侧光。若主题是迷离梦境，强反射、过曝和不明光源也可能是表达选择，应按目标控制，而不是全部修成影棚照。

材质 prompt 用“材料＋相关表面特征＋光线下表现”即可有针对性，不必每次列 PBR 属性。例如“手作粗陶，口沿不完全规整，侧光显出细小颗粒”；“剪纸山体，层层纸边投出短小阴影”；“湿润黑石，局部反光清楚，未沾水部分较哑”。不要把同一表面同时要求完全哑光和清晰镜面反射，除非明确不同区域。

图像发灰先查主体与背景明度关系；体积扁先查受光面是否区分；材质像塑料先查高光形状、反射和表面尺度；换背景后不自然先查光向、色温和旧环境反射。诊断后只修相关条件，不把“电影光”“真实质感”当通用解法。

方法参考：[Ctrl+Paint 绘画基础资料中的明暗与光](https://www.ctrlpaint.com/library)、[Adobe 材质属性](https://helpx.adobe.com/dimension/desktop/using/standard-materials.html)。材质术语不代表工具开放对应数值参数。
