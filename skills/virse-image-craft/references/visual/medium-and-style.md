# 媒介与风格

“不像参考”“太光滑”“想更有手感”时，把风格拆成能看见的规律：形状、线条、明暗、颜色、边缘、纹理、制作痕迹与空间方式。媒介名称可快速定方向，具体规律用来校准，不需要把每项都列全。风格可以混合，但须说明各部分怎样分工。

| 媒介或方向 | 按目标选择与表达 | 取舍、诊断 |
| --- | --- | --- |
| 线描、漫画 | 选线的粗细变化、连续程度、阴影语言，如“外轮廓较粗，内部结构线简洁，暗部用疏密排线” | 均匀黑边可能抹平层级；线条粗糙是否保留取决于表达 |
| 水彩、水墨 | 选透明叠色、渗化、干湿变化与纸面留白，如“湿画背景自然渗开，人物眼口保留较明确的笔触” | 全图糊开会失去识别；不要同时要求每条边都刀切清晰 |
| 油画、厚涂 | 选覆盖感、笔触尺度与塑形方式，如“较大的块面塑造脸部，厚色堆在受光处” | 细节密度要匹配观看尺度，不能只靠覆盖一层随机纹理冒充笔触 |
| 矢量感、扁平图形 | 选轮廓几何、色块、有限渐变与空间简化 | 生成为位图只是矢量外观；可编辑路径须用相应绘图工具制作 |
| 木刻、丝网、套色印刷 | 选刀痕、颗粒、叠印关系与是否故意错位 | 瑕疵是可控语言，不能牺牲必须可读的文字或识别特征 |
| 黏土、剪纸、毛毡等手工感 | 选材料边缘、厚度、纤维、接缝和相应光影 | 不同材料的变形与表面响应不同；“手作”不等于统一旧化或脏污 |
| 摄影、3D 渲染 | 选真实或风格化的光学、材质与空间线索 | 不能把渲染感自动当成劣质；产品可需要精确干净，也可需要日常磨损 |

边缘有硬、软、断续或融入周围的变化。硬边适合需要明确的轮廓、图形与局部强调；软边与消失边可融合体积、距离或气氛。不要求写实绘画所有地方都勾线，也不强迫木刻和扁平插画加入柔边。

例：“人物用简洁黑色线描，城市背景用少量水彩铺色，人物轮廓保持明确”，让混合媒介有分工；“二维贴纸角色出现在真实桌面上，保留贴纸平面轮廓，只让桌面的光影影响贴纸表面”，让风格差异成为意图。

风格漂移先找丢失的规律：线粗变了、边缘全软、笔触尺度不一致，还是新加了不需要的体积光。选最有辨识度的特征修正，不用堆叠“高级、艺术、精美”。若参考提供风格而非内容，明确哪些特征借用、哪些主体与构图不借用；不要凭艺术家或媒介名替用户补未确认的整套画面方案。
