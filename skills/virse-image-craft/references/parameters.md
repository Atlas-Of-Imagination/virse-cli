# 参数

参数控制如何执行，prompt 描述要出现什么。先由用途判断画幅、尺寸、保真程度和透明性。只解释概念或给未绑定模型的提示方案时，直接说明取舍，无需登录或远端查询；核实特定模型的可用配置或实际执行时，再查当前模型或工具的真实选项。同名参数跨模型可能含义、范围和效果不同。

| 参数概念 | 作用与选择 | 边界、检查方法 |
| --- | --- | --- |
| 画幅比例与像素尺寸 | 比例决定容器形状，像素决定文件分辨率；依据使用位置、裁切余量和细节需求选择 | 横图不代表主体横向铺满；prompt 写“4K”不等于设置 3840×2160，交付检查实际宽高 |
| quality 或质量档 | 可能影响计算投入、细节、时延与费用；在当前模型支持范围内按用途取舍 | 最高档不能修复错误构图、参考或内容冲突；不同模型的 high 不等质 |
| 输出数量 | 用于探索备选或满足确定数量 | 多张不保证有一张合格；数量与费用授权须明确，不自动批量试错 |
| seed | 在支持的模型和固定执行条件下帮助控制随机起点、做对照 | 不保证跨模型、跨分辨率或更新后复现；同 seed 不等于同一身份，不从图像猜数值 |
| 图像变化强度、denoise 等 | 某些编辑模型用它平衡贴近原图与重新创作 | 先确认数值增大代表更大改动还是更强保留；变化不足可能改不动，过大可能漂移，范围和默认值依工具 |
| 参考权重或保真选项 | 在提供此能力时调节输入影响 | 构图、身份和风格未必能独立控制；不是“越高越好”，过强可能锁住不需要的背景 |
| CFG、guidance 等 | 部分模型用来调节条件引导 | 含义与有效范围依采样方法；高值可能生硬或失真，不能把一套值搬到所有模型 |
| steps、sampler、scheduler | 部分扩散工具暴露采样过程 | 更多步数可能耗时且不改善结果；很多模型不开放这些选项，不编造参数 |
| negative prompt | 有些模型提供独立排除条件 | 支持情况与解释方式不通用；关键目标仍写在正向内容中，负词不能修复结构依据不足 |
| mask | 限定编辑范围或提供软边过渡 | 通道、尺寸、极性、透明度解释由工具决定；先确认预览与实际选区，不能假设白或黑总代表编辑 |
| 输出格式、透明度与压缩 | 用于透明素材、网页文件或保留细节 | JPEG 不含 alpha；检查实际通道、边缘与压缩损伤，不能只信文件名或 prompt |

比较参数时先固定目标、prompt 和参考，再改变与问题有关的项，避免同时换模型、尺寸、强度后误判原因。只有在支持且有助于比较时固定 seed；不要因此阻止合理的构图探索。

质量偏好不构成执行授权。涉及 Virse 选型、参数确认和提交时，按名称读取 `virse-creation`，核对当前会话已有授权范围。不得把“想要最好效果”理解成可任意提高费用、输出数量或重试次数；已有明确配置则按范围继续。

方法参考：[OpenAI 图片提示中的参数与内容区分](https://developers.openai.com/api/docs/guides/image-prompting)、[Gemini 图像配置](https://ai.google.dev/gemini-api/docs/image-generation)。
