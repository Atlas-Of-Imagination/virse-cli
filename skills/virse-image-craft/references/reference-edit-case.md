# 图片参考与改图：模拟案例

目标是为已有香水做活动主图：保留瓶身轮廓、瓶盖和准确标签，借另一张参考的侧光与浅色背景，右侧留出放活动文字的空间。两张图各有职责：产品原图提供身份与结构，氛围图只提供光色，不照搬其中器物和文字。已有主体必须保留，因而先判断当前编辑能力能否用原图改背景；不直接把两张图混合作为新产品生成。模型、比例与编辑参数按当前能力和实际用途选择，提交遵守已有授权。

假设首轮产物的背景与留白符合要求，但瓶盖变圆、标签字样也被重写。这里可直接观察的是轮廓和文字与原图不同；“氛围参考权重过大”只是候选原因，还可能是输入角色不清或所选编辑能力重画了主体。不能仅凭成图断言某个参数失效。先核对实际提交的原图和参考角色，再比较原图与产物的关键局部。

本轮最小修正是保留已经认可的背景方向，把原产品区域作为保留对象，只调整其外部背景与接触阴影。若当前能力支持局部编辑，可限定修改区域；若精确标签仍无法保住，则评估原产品抠图合成与阴影处理，不用反复强调“文字正确”替代方法选择。补充表达可以是：“沿用原瓶与标签，只把外部背景改为参考中的浅色侧光环境；右侧保持干净，保留瓶底接触关系。”这段话须按真实输入与能力改写。

修正后应在最终使用尺度查看产品辨识与留白，再放大对照瓶盖、标签和边缘，并检查新背景的光向是否与原瓶相容。只有实际结果满足保留项，才交付可用图片与必要文件；若采用后期合成，就说明成品的实际处理方式。以上问题和修正均为模拟推演，未执行生成或验证改善，不存在可宣称已通过验收的成品。
