# 编辑与处理

已有图片时先选能保留所需内容的方法。用户说“改一下”不代表允许全图重画；同时区分视觉相似、结构不变与像素不变。改变范围越大，身份、细节和布局漂移的风险通常越高，不能用一句“其他不变”保证保真。

| 方法 | 何时适用、怎样表达 | 取舍与问题诊断 |
| --- | --- | --- |
| 指令编辑 | 需要换装、改材质、调整全图氛围等语义变化；指明对象、变化和保留项 | 可联动多处；若连未授权区域也变，缩小目标、补参考或改局部方式 |
| inpaint 局部重绘 | 要替换明确区域、修手或补缺损，且工具支持蒙版；描述选区应出现什么及其接缝关系 | 蒙版太紧可能缺乏修复空间，太大会伤及保留项；按工具合同解释蒙版，不能跨平台假设黑白极性 |
| 扩图 | 原图内容可保留，缺的是边界外空间；确定最终画幅、向哪边扩、原图在新图中的位置 | 描述新增地面、墙面、天空等连续结构；接缝、重复物与透视断裂须实看 |
| 合成 | 需要把指定主体放入指定环境、保留真实元素 | 核对尺度、地平线、遮挡、接触阴影、反射、光色与颗粒；局部生成可辅助融合，不自动保证原物像素不变 |
| 裁切与缩放 | 构图或交付尺寸变化，主体内容本身已合适 | 裁切会丢内容，缩放不会凭空恢复真实细节；先判断边缘和文字是否被切掉 |
| 去背景与透明处理 | 需要独立主体、贴纸或产品素材 | 检查 alpha、细发、透明物、白边；棋盘图案不是透明通道，阴影是否保留由用途决定 |
| 放大、降噪、锐化、校色 | 原图结构正确，问题是尺寸、噪点、清晰度或色调 | 生成式放大可能编造纹理和文字；过度锐化会出光晕，降噪会抹细节，校色会改变品牌色关系 |

在 Virse 执行时，按名称读取 `virse-creation` 获取实际操作、输入和蒙版合同；这里的方法分类不表示每个模型都支持这些操作。

## 把修改变成可检查的差异

保留项写与本次风险相关的部分，例如“只把杯身改为半透明蓝玻璃；杯柄形状、口沿角度、标志文字、机位和背景位置保持”。不必对无关元素逐项承诺；也不能同时要求大幅转机位和所有遮挡关系不变。

删除对象时补充空出来的位置应如何成立：“移除桌上的花瓶，露出连续的木桌纹理，修复后方墙面，取消花瓶投影”。否则模型可能留下阴影、重复纹理或空洞。替换背景时注意旧环境是否仍在镜面和玻璃里；单改背景颜色不足以融合高反射主体。

合成可先选与场景相容的主体视角，再匹配落地和光色。脚底悬空先查地面接触，人物像贴纸先查边缘、光向和清晰度；不要对所有问题统一加模糊。平面拼贴若本来追求剪纸边缘，则按该媒介判断，不强求写实融合。

需要区域像素不变时，优先使用保留原像素的裁切、蒙版、图层合成等方法；生成式编辑提供的是受约束重绘。反复局改仍牵连主体、复杂变视角持续失真时，停止累加限制，改用结构参考、分步合成、适合的处理工具或经用户接受的新画面方案。
