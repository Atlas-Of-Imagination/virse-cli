# 提示词取舍与表达

用户给出想法、草稿 prompt，或抱怨“出图不对”时，先判断他要表达什么、图片用在哪里、哪些要求不能变。详细需求先整理顺序、消除歧义，不擅自增加镜头、配色或场景；宽泛需求才补充有助于实现目标的选择。影响主方向的选择拿不准时询问，非关键细节可提出与用途相符的建议。

## 把可见关系说清楚

提示词的作用是让模型知道要形成什么画面。用具体主体和关系代替孤立的评价词；长度由内容决定，自然段、分点或短句均可，不要求固定字段和字数。

| 用户表达 | 判断与可用表达 | 取舍 |
| --- | --- | --- |
| “这张太乱” | 找到真正抢夺注意力的元素；如“保留热闹集市，人物面部周围不要悬挂招牌，远处摊位细节降低” | 乱可能是题材所需，不自动清空背景 |
| “产品更有分量” | 若来自体积感，表达支撑、视角与明暗，如“略低视角，底座完整落地，侧面保留暗部” | 不自动改成黑金配色或奢侈品广告 |
| “手绘一点” | 询问或从参考判断是线条、笔触还是色块；如“轮廓有轻微断续，保留纸面与水彩晕染” | 不同时叠加油画厚涂、矢量平涂等冲突语言 |
| “海报突出活动信息” | 写明第一眼读什么、完整文案及文字位置，如“主标题‘山野放映’在上部，日期地点作为一个较小信息组” | 字体、文字准确性与可编辑性需要分别检查 |

多个主体直接用名称、特征或输入图编号指代，避免“他”“它”“那个”混淆。动作写清谁对谁做什么、接触哪里；空间写清相对位置与遮挡。例如“红衣女孩把伞递给蓝衣男孩，两人手部在画面中央接触”，比“两人互动”更能约束关系。

优先正面描述目标；必要排除项用于保护真实约束。要空街就说明路面开阔、没有行人车辆；要保留杂乱生活感，就不要惯性加“干净背景”。工具存在独立 negative 字段时再查其合同，不把通用禁词串当成必需品。

## 根据交付组织内容

只要 prompt 时，直接交最终文本。用户需要选择方向时，提供在表达、构图或媒介上有实际区别的候选，而非换同义词。用户指定模型时，可在必要处说明该模型可能不支持的输入或参数；无实际查询依据，不承诺文字、人数或保真程度。

精确文案逐字引用，并说明层级、位置和允许换行的位置；不要让模型自行编造联系方式、产品卖点或统计数据。若文字很多且必须准确、可改，建议生成底图后用排版工具放字；只有用户同意调整交付方式才实施。

检查 prompt 时问：主目标是否被次要装饰淹没？同一个对象是否被要求同时正面与侧面、全景与极近特写？“浅景深”是否与全部标签可读冲突？先解决冲突，不靠增加“高质量”“大师作品”掩盖。参考图的风格与主体须分开说明，编辑须另写改变项与保留项。
