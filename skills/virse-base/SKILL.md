# Virse 操作基础

Virse 是 AI native 的创作系统，用画布连接想法、素材、审美、工具与模型，支持图片、视频、3D 和文本。资源目录管理素材与归属，画布组织创作输入、过程与结果。

只读当前任务所需参考，已读且适用的内容沿用，链接不自动加载内容。

## 共同约定

- 沿用用户明确的身份、后端与任务范围；临时操作优先传 `--org/--canvas`，不为单次任务更改默认设置。
- 资源项、asset、画布 Space 与节点 ID 分别核对，不将显示名称或另一类 ID 代入。
- 区分请求受理、任务完成、内容保存和作品验收；写入结果不明时保留原请求与任务身份，先查证再恢复，不盲目重发。

业务技能通过宿主技能列表定位本技能；`virse-base/references/...` 表示本目录内的参考路径，不是相对于当前工作目录。这里只读当前任务需要的参考，不要求每次业务操作重新登录或重读全部文档。

用户指定后端时，在首条远端命令前设置 `VIRSE_BACKEND_URL`。

## 连接并确定范围

CLI 和登录态已就绪时直接继续原任务。需要安装或登录时，按[连接指引](references/contracts/connection.md#安装与首次登录)执行，并实时转达 CLI 的授权提示；登录后核实身份、确定空间，再继续原任务。参数不明确时，只查对应命令的 `--help`。

身份与后端、退出授权、默认配置和余额说明按需读取[连接与操作范围](references/contracts/connection.md)，只取当前相关段落，沿用已明确的身份与上下文。资源项、asset、画布 Space 与节点身份不明确时，读[对象身份](references/context/objects.md)。

## 按当前目标选择

| 用户要做什么 | 入口 |
| --- | --- |
| 开启 Ultra Design／全能创作，统筹完整创作项目 | `virse-ultra-design` |
| 与用户共同建立或完善品牌系统，做画布实验并交付可持续取用的品牌文件夹 | `virse-brand-center-creator` |
| 跨来源汇集并构建素材库、规划整理已有资产库、上传替换、批量导入、回收或下载打包 | `virse-assets` |
| 理解画布、创建与整理内部节点、分组排版、设置生成输入连线与讨论 | `virse-canvas` |
| 查看或调整访问、分享、撤权、接受邀请 | `virse-sharing` |
| 探索创意与视觉方向、找灵感参考、验收画布作品的品牌一致性，或生成修改图片、视频、3D、文本并迭代 | `virse-creation` |
| 写好生图提示词、理解参考图、选择视觉表现，或诊断图片效果 | `virse-image-craft` |
| 写好视频提示词、选择创作模式、设计动作镜头与声音，或诊断视频效果 | `virse-video-craft` |
| 找到、放置、运行或管理已有智能工具 | `virse-tools` |
| 从画布发现可复用流程并总结成工具，或编写、构建、测试与发布工具包 | `virse-smart-tool-creator` |
| 从画布理解并发展审美方向、总结审美模块，或创建训练、调优测试与保存审美 | `virse-aesthetic-creator` |
| 围绕画布材料连续创作、组合多步操作与反馈，或继续创作家会话 | `virse-composer` |

根据用户目标选择业务入口，不要求每次重读本技能。需要画布内连续创作时可主动选择 Composer；精确管理或指定模型、工具产物时优先 CLI 直做，复杂程度本身不是委派理由。普通审美查阅与取用读对应业务技能的审美参考，不启动作者流程。明确任务跨领域时直接补读所需参考；Skill 名称和链接本身不会自动执行路由。所需入口未安装时说明缺少哪个包，不假设其内容已经加载。

按对象与目标区分相近入口：画布创建及已有节点的字段配置走画布；提交新作品走创作；资源回收站走资产。模型收藏走创作，工具收藏与可用范围走工具，资源访问与分享走共享。导入批次恢复不等于生成重试；工具内部运行 Agent 也不等于向 Composer 会话交办任务。

## 更新与迁移

同一套 Virse 业务技能和 base 使用相同来源、分支或发布 tag，并安装在同一范围；引用不存在时核对版本并一起更新，不猜测缺失规则。旧 `virse` / `virse-setup` 的迁移按[旧入口迁移](references/contracts/skill-migration.md)处理。

## 交付与异常

连接完成以真实身份和明确空间为准；查询失败不能当成空账号或空空间。遇到结果不确定、异步状态或修订冲突，按[执行结果与恢复](references/contracts/execution.md)对账；不要为排查自动切换账号、重建对象或重发收费任务。
