# 品牌文件夹交付与持续取用

## 将系统整理为实际品牌文件夹

沿用开工时确定的 Virse 资产管理品牌文件夹，按用户确认的范围整理并完善实际内容；尚无位置时，先核实组织与可写父目录再建立。名称和层级服务于取用习惯，可随建设逐步充实，完成以约定内容实际可用为准。目录操作、上传及画布媒体另存读取 `virse-assets` 对应参考；需要理解或调整画布时读取 `virse-canvas`，仅归档资料不重做已确认作品。

让用户从文件夹入口知道品牌适用于谁、先读什么、去哪里拿材料。按本次需要组织以下内容角色，不强制同名文件夹：

| 内容 | 应能怎样使用 |
| --- | --- |
| 品牌总览与使用入口 | 快速理解确认的品牌叙事、范围、保留项和内容位置，定位规范及实际文件 |
| 规范与可用资产 | 查到某条用法，就能找到对应资产、示例和使用条件；辨认产品、活动或渠道的局部规则 |
| 应用与可复用示例 | 看懂规则怎样组合，并能换内容完成约定的常用任务 |
| 探索、实验与待补项 | 继续讨论时找到依据与未决问题，清楚哪些内容尚未采用或尚未交付 |

保留已采用素材与实验画布的对应关系，原始来源及取得方式可追溯；说明文字、目录与布局表达关联，不为出处或阅读顺序添加创作输入连线。探索画布可以保存在品牌文件夹中，实验结果不会自动成为可用规范。

需要 DOCX、PDF、色板、Logo 或其他实际文件时，按[规范与资产](guidelines-and-assets.md)制作、检查、上传，再核对真实资源身份与可用内容。画布文字不自动成为 Word/PDF，组合也不会自动导出完整指南；截图、文件名、字体安装或来源链接不能冒充相应原件已经入库。格式、字体或其他能力未核实时保留缺项和实际可取用方式。

## 核对约定用途下的质量

- **品牌依据一致**：叙事、文案事实、色值、字体和所选素材符合用户采纳的判断，规范、示例与实际文件对应。新应用没有悄悄改写品牌整体或其他产品线的规则。
- **真实应用成立**：按[应用实验](explore-and-test.md)回看约定场景、尺寸和内容，记录实际检查到的结果及未验证项；不从单个样张推断所有场景。
- **文件可以使用**：打开或渲染文档检查文字、字体、分页、图像和数值；检查独立素材的实际格式、尺寸、背景及需要的可编辑性。视频按需求播放和听音。没有查看能力时明确未验证的质量。
- **能够找到并复用**：用一项约定的真实任务走一遍“从入口找到规则与资产→选择正确材料→完成应用”。必要时让没有参与构建的 Agent 仅凭文件夹资料与任务试用；沿用实际生成授权，缺失的说明或材料先修正，不以熟悉项目的解释代替交付。

核对实际目录成员、规范、文件与相关画布，确认必需成果已落到开工时确定的品牌文件夹。阶段成果返回对应画布的已核实链接及简短变化说明，保持品牌文件夹入口可找到；最终交付同一文件夹的真实位置或已核实可访问链接，说明可直接使用的内容和仍存在的缺项。未取得文件、仅有聊天建议或生成状态成功时，不报完整交付。

## 依据品牌中心继续设计

用户要以已有品牌中心做新设计时，先读其总览与本次产品、活动、渠道相关的规范、实际资产和示例。形成当前任务的目标、保留项、输入角色与可变部分；已有要求充分就进入制作，缺少影响方向的内容才补问，不重新建立整套品牌定位。

新作品制作使用 `virse-creation`，需要专业表现方法再补图像或视频技巧；围绕实际用途检查，并可用 `virse-creation` → `references/brand-review.md` 检查品牌符合情况。使用当前任务画布推进并返回实际链接，按用户保存意图归入品牌文件夹。只有用户认可其可复用价值时，才把新判断或应用沉淀进对应规范和资产；局部任务选择保持局部。

可参考 [Corebook 规范、素材与使用情境的连接](https://www.corebook.io/brand-stories/how-to-create-online-brand-guidelines)。采用其内容组织思路，不假设 Virse 已有自动同步、品牌专用对象或跨平台实时更新能力。
