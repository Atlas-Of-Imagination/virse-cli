# CLI 能力缺口

对照[《Virse CLI 能力清单》](https://uwo12t0g4tq.feishu.cn/wiki/Ayr5wJ1YBiRM6LkqzrgcQyAlnWg)，更新于 2026-10-29。本清单区分 CLI 命令缺口与后端/浏览器前置，不表示这些能力都已有可直接接入的 HTTP API。

本轮补齐：空间及角色列表、创建画布与内容清单、资源筛选排序、批量移动/复制、预览获取、模型目录与收藏、余额查询，以及文本/去背景/超清放大/扩图快捷命令。扩图的 `mask_source` 需要配套后端版本；它消费已准备并上传的蒙版图片，不提供本地画板编辑。

补充边界：

- `generation submit --file` 已能调用后端声明的其他操作；部分 3D 处理、矢量化、图层分离等不能算完全未接入，但仍缺完整专用交互、结果交付和验收。
- 画布创建沿用无幂等回执的现有接口，不自动重试；未知结果需先查询目录。
- Canvas contents 使用资源路径或资源 ID，返回内容投影及 offset 分页，不是节点布局编辑 API，也不宣称跨页快照一致性。
- 预览是授权展示内容；没有封面时明确报错，不回退到原文件。服务端可能允许只读文档、视频或模型的展示，而不允许原件下载。
- MCP 按现有方向不纳入本轮接入；网页本地面板、键鼠和显示样式不是 CLI 业务缺口。

本轮现有接口接入细节与局部限制见 [CLI 工作流](CLI-WORKFLOWS.md)。这些限制不通过猜测版本、伪造取消或重复创建来绕过。
